
# CLONE EGG


## Descripción

Clone de la plataforma EGG
En este proyecto no se distribuye ningun contenido de un curso, si no es el usuario que accede a esto mediante su id de usuario

## Requisitos

Antes de ejecutar el script de Python o el proyecto de React, asegúrate de tener instalados los siguientes programas en tu sistema:

- [Python 3.x](https://www.python.org/downloads/)
- [Node.js y npm](https://nodejs.org/en/download/)

## Ejecutar el Script de Python

1. **Clona el repositorio** o descarga los archivos necesarios.

2. **Instala las dependencias** de Python si es necesario. Este script utiliza la biblioteca `requests`, por lo que debes instalarla usando `pip`:

    ```bash
    pip install requests
    ```

3. **Ejecuta el script** proporcionando el código del alumno como parámetro. Usa el siguiente comando:

    ```bash
    python script.py <alumno_id>
    ```

   Reemplaza `<alumno_id>` con el código del alumno que desees consultar. Por ejemplo:

    ```bash
    python script.py 65a**********
    ```

## Configuración y Ejecución de un Proyecto de React

1. **Instala las dependencias** del proyecto usando npm:

    ```bash
    npm install
    ```

2. **Inicia el servidor de desarrollo** para ejecutar el proyecto:

    ```bash
    npm run dev
    ```

    Esto iniciará el proyecto en modo de desarrollo, y podrás acceder a la aplicación en `http://localhost:3000`.
